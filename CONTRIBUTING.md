# Contributing

Read AGENTS.md and docs/research/product-strategy.md. Scope changes in a branch. Run npm ci, npm test, npm run typecheck, and npm run build. Use scoped test accounts; do not inspect customer journals. Document migrations, recovery effects, and verification limits.

Keep traditional source material attributed. Do not add guaranteed-outcome claims, invented testimonials, fear-based upsells, or unverified astronomical calculations.
